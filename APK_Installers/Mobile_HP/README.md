# 📱 IDLIX Player untuk Android Mobile (Smartphone & Tablet)

Folder ini berisi paket instalasi APK khusus perangkat layar sentuh (**Smartphone Android & Tablet Android**).

---

### 📂 File yang Tersedia

* **`IDLIX-Mobile-Modified (Auto-Detect).apk`** ⭐ **(Versi v1.0.3)**
  - **Ukuran**: ~23.1 MB
  - **Fitur Khusus**: Dilengkapi tombol **"Auto-Detect Server"** di menu Settings. Memudahkan HP mendeteksi IP backend laptop secara otomatis tanpa perlu mengetik manual.
  - **Material 3 & Dual-Mode Player**: Tampilan antarmuka modern dengan transisi mulus dari pemutar inline 16:9 ke layar penuh landscape, navigasi swipe gestures, dan Picture-in-Picture (PiP).

---

### 🛠️ Cara Instalasi ke HP Android

1. Salin file `IDLIX-Mobile-Modified (Auto-Detect).apk` ke memori HP Anda (melalui kabel USB, WhatsApp Web, Telegram, Google Drive, atau download langsung dari GitHub).
2. Buka aplikasi **File Manager** bawaan HP Anda.
3. Cari file APK tersebut di folder **Download** atau folder penyimpanan Anda.
4. Ketuk file APK dan pilih **Install**.
   > *Jika muncul peringatan "Install dari Sumber Tidak Dikenal", berikan izin (Allow) pada browser atau File Manager Anda.*
   > *Jika muncul peringatan Play Protect, ketuk "Detail Selengkapnya (More details)" lalu pilih "Tetap Instal (Install anyway)".*

---

### ⚙️ Konfigurasi Setelah Terpasang
1. Pastikan server backend di laptop sudah menyala (jalankan `1-JALANKAN-SERVER.bat`).
2. Pastikan HP dan Laptop terhubung ke jaringan Wi-Fi yang sama.
3. Buka aplikasi IDLIX di HP -> Masuk ke tab **Settings (Pengaturan)** ⚙️.
4. Ketuk tombol **"Auto-Detect Server"**.
5. Server otomatis terdeteksi dan aplikasi siap memutar film serta serial TV!
